# H2 Place Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the place table's current tab as pins on a Kakao map above the table, linked both ways with the table's open row.

**Architecture:** A new `shared/places/PlaceMap.tsx` draws the map. It reuses `CourseMap`'s loader pattern. `PlaceTable` owns the one `open` state and hands it to both the rows and the map. `PlaceTable` also gains an `origin` prop, which its two callers pass in. The backend does not change.

**Tech Stack:** React 19, TypeScript ~6, Tailwind v4, Kakao Maps JS SDK (through `loadKakaoMaps`), oxlint, and headless Chrome over CDP for UI checks.

**Spec:** `docs/superpowers/specs/2026-10-09-place-map-design.md`

## Global Constraints

- Package by feature. The map lives in `frontend/src/shared/places/` because two features render the table. Features never import each other.
- No new dependencies.
- Use the same box as `CourseMap`: `h-60 md:h-80 overflow-hidden rounded-3xl border border-zinc-200 bg-zinc-100`, `animate-pulse` while loading, and `aria-label="맛집 지도"`.
- When `loadKakaoMaps()` resolves to `null`, render no map box at all.
- The map refits its bounds only when the pin set changes (a tab switch). Opening a row or sorting must not move the map.
- Copy is Korean. No emojis.
- Frontend checks are `cd frontend && npm run build && npm run lint`.

## Review Focus

1. Sorting a column or opening a row must not refit the map. A refit snaps away whatever the user dragged to. Pinned by Task 2, check R1.
2. When a tab has no places, the map unmounts. Going back to a tab with places must bring the map and its pins back. Pinned by Task 2, check R2.
3. A keyboard user who activates a pin must land on the row that opened, because the pin's DOM is rebuilt. Pinned by Task 2, check 2 (focus assertion).
4. Pin clicks must not leak into the map as a click or drag. `clickable: true` handles this. The fake SDK cannot exercise it, so the reviewer checks it by reading the code.
5. Place names and ids reach the DOM only through `textContent`, `setAttribute` and `CSS.escape`, never through `innerHTML`. The reviewer checks this by reading the code.

```tsx
import { useEffect, useRef, useState } from 'react'
import type { Place } from './types.ts'
import { loadKakaoMaps } from './kakaoMap.ts'
import type { KakaoMap, KakaoMaps } from './kakaoMap.ts'

type Props = {
  places: Place[]
  origin: { lat: number; lng: number }
  open: string | null
  onPick: (id: string) => void
}

// a grey dot per restaurant; the open row's dot grows in the accent color with its name beside it
function pin(place: Place, open: boolean, onPick: (id: string) => void): HTMLElement {
  const button = document.createElement('button')
  button.type = 'button'
  button.setAttribute('aria-label', place.name)
  button.setAttribute('aria-pressed', String(open))
  button.className = 'relative block p-1.5'
  const dot = document.createElement('span')
  dot.className = open
    ? 'block size-4 rounded-full bg-accent ring-2 ring-white shadow-[0_4px_12px_-4px_rgba(0,0,0,0.4)]'
    : 'block size-3 rounded-full bg-zinc-500 ring-2 ring-white'
  button.append(dot)
  if (open) {
    // positioned off to the side so the dot, not the label, sits on the place
    const label = document.createElement('span')
    label.className =
      'absolute left-full top-1/2 max-w-40 -translate-y-1/2 truncate rounded-full bg-white px-2 py-0.5 text-xs font-medium text-zinc-900 shadow-[0_4px_12px_-4px_rgba(0,0,0,0.3)]'
    label.textContent = place.name
    button.append(label)
  }
  button.addEventListener('click', () => onPick(place.id))
  return button
}

// where the search was made from
function here(): HTMLElement {
  const element = document.createElement('div')
  element.className = 'size-3.5 rounded-full bg-zinc-900 ring-4 ring-white/80'
  return element
}

// the place table's current tab on a Kakao map; pins open their row and the open row's pin stands out
export default function PlaceMap({ places, origin, open, onPick }: Props) {
  const container = useRef<HTMLDivElement>(null)
  const map = useRef<KakaoMap | null>(null)
  // undefined while loading, null when there is no map to show
  const [maps, setMaps] = useState<KakaoMaps | null>()

  useEffect(() => {
    let mounted = true
    loadKakaoMaps().then((loaded) => mounted && setMaps(loaded))
    return () => {
      mounted = false
    }
  }, [])

  // only a new set of pins (another tab) refits the map; opening a row or sorting leaves it where the user moved it
  useEffect(() => {
    if (!maps || !container.current) return
    const center = new maps.LatLng(origin.lat, origin.lng)
    if (!map.current) {
      map.current = new maps.Map(container.current, { center, level: 5, draggable: true, scrollwheel: false })
      map.current.addControl(new maps.ZoomControl(), maps.ControlPosition.RIGHT)
    }
    const bounds = new maps.LatLngBounds()
    bounds.extend(center)
    places.forEach((place) => bounds.extend(new maps.LatLng(place.lat, place.lng)))
    map.current.setBounds(bounds)
    const marker = new maps.CustomOverlay({ position: center, content: here(), yAnchor: 0.5 })
    marker.setMap(map.current)
    return () => marker.setMap(null)
  }, [maps, places, origin])

  useEffect(() => {
    if (!maps || !map.current) return
    const pins = places.map(
      (place) =>
        new maps.CustomOverlay({
          position: new maps.LatLng(place.lat, place.lng),
          content: pin(place, place.id === open, onPick),
          yAnchor: 0.5,
          zIndex: place.id === open ? 1 : 0,
          clickable: true,
        }),
    )
    pins.forEach((overlay) => overlay.setMap(map.current))
    return () => pins.forEach((overlay) => overlay.setMap(null))
  }, [maps, places, open, onPick])

  if (maps === null) return null
  return (
    <div
      ref={container}
      aria-label="맛집 지도"
      className={`mt-6 h-60 overflow-hidden rounded-3xl border border-zinc-200 bg-zinc-100 md:h-80 ${maps ? '' : 'animate-pulse'}`}
    />
  )
}
```

The pins effect runs after the bounds effect in the same commit, so `map.current` exists by then.
